02 / Maps & supplied artwork

USGS Grand Teton quadrangle, Wyoming, 2021, US Topo 7.5-minute series. The field strip uses a crop of this actual map, recolored in the browser. The full map is available from the original USGS source. USGS map reuse policy.

Northstar logos, GrandTopo.png, GrandTopo-expanded.png, FantasyMap.png, the Starboard graphics, and Goblin Survivors screenshots were supplied by the site owner. Footer contours use the supplied transparent GrandTopo asset. Celestial orbits, route diagrams, and globe lines are custom decorative graphics. The coordinate labels identify the Teton area; the scale graphic is a design motif. This page is not a navigation tool.

04 / Motion references

Neo Neo informed the ruled modular editorial grid. Hello Monday provided a reference for illustrated presentation and progression into project imagery. Studio Dumbar's Instagram motion system informed the use of a consistent family of eased movements, depth, and scroll-related behaviors.

These are design references. Their scripts, artwork, and brand assets were not copied. All custom motion is implemented in this site's JavaScript; button and image hover effects use CSS. Use the motion control in the header to pause decorative animation. The site also honors the system reduced-motion preference.

05 / Project content

Thunderbird remains a coming-soon project, matching the supplied project page. Landscape artwork is an atmospheric study, not gameplay. The site presents games and studio information. Personal portfolio pages are not part of the published site. Thunderbird wordmark and feather artwork were supplied by the site owner from the Thunderbird branding folder. Instagram slots are initially empty and load third-party embeds only on request once public post links have been configured.
